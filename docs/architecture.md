# 项目架构（Phase 0）

## 目标

这是一款以文字推动的黑白 2D 游戏。纯黑背景上，简笔画和声音随文字变化。当前样片的流程是：封面 → 逐字出现的剧情 → 点击推进与滚动回看 → 场景和声音反馈 → 选择对话气泡 → 点击气泡改写回答。

## 边界

| 目录 | 职责 |
| --- | --- |
| `scenes/` | Godot 可编辑场景与节点布局 |
| `src/core/` | 启动和页面切换 |
| `src/narrative/` | 按顺序读取内容并发出当前文字事件 |
| `src/presentation/` | 画面与声音反馈 |
| `src/interaction/` | 对话气泡的手绘外形与后续交互接口 |
| `content/` | 剧情数据，不放在脚本里 |
| `themes/`、`assets/` | 字体、音效和统一主题 |

`Main` 只负责切换封面与叙事场景。`NarrativeRunner` 只负责读取和推进事件，不直接控制场景、音频或画面。叙事场景收到事件后把 `cue` 交给 `Presentation`。界面分为上方画面、中部可滚动剧情、下方对话区；互动阶段可调整三块区域的高度。后续战斗或解谜可沿用这个布局变化。

## 内容格式

`content/chapters/prologue.json` 的 `steps` 是有序文字事件。每条含 `id`、`text` 和可选 `cue`。`choices` 定义结尾的两句对话。当前 cue 只有 `dark`、`reveal_room`、`start_tick`、`stop_tick`、`none`；它们是这段样片的表现指令。

## 后续里程碑

1. 试玩样片，确认画面大小、文字阅读节奏和气泡交互。
2. 根据试玩结果定义正式 Narrative Runtime 和分支内容格式。
3. 再制作战斗、解谜与物理手绘原型。
